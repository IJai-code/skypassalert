# Field log

*Ishaan's outdoor observations, in his own words. These feed the accuracy report (Phase 8). Claude Code never writes entries here.*

**Privacy:** record the city or a public landmark only, never a home address.

## Protocol (short version; full version in Phase 8)
1. Sync the phone clock to network time and note the prediction's data age.
2. Before going out, write down the predicted times, directions and peak elevation.
3. Outside: note when you first see it, its highest point, and when it disappears. Did it fade out, go behind something, or reach the horizon? A video with an on-screen clock is best.
4. Compare its brightness with a known star or planet.
5. Note the sky conditions.
