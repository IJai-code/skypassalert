# Growth assets

The launch kit, filled in during Phase 7 (strategy in `../GROWTH.md`). Planned files:

| File | What it is |
|---|---|
| `LAUNCH.md` | Soft launch (about 10 families) → staged public launch, timed by the launch-window finder |
| `messages/en.md`, `messages/zh-Hans.md` | Ready-to-paste posts for WeChat, WhatsApp, Nextdoor, Facebook groups, PTA newsletters, each with its own `?s=` link |
| `flyer.html`, `poster.html` (+ PDFs) | Print-CSS one-pagers with QR code |
| `OUTREACH.md` | Verified local outreach targets (schools, libraries, astronomy clubs, PTAs, local news) |
| `SKY-CALENDAR.md` | 90-day plan of verified sky events, with a post in EN and zh for each |
| `WEEKLY.md` | Weekly loop: what to check, post and fix, and how to read the numbers |
| `../MEDIA.md` | One-page press/about kit (student privacy: first name and city only by default) |

Rules for every asset:
- No fabricated testimonials, counts or endorsements.
- Respect group rules and ask admins first.
- Never spam.
